name: Shopper category hierarchy
description: User's current preference for a multilevel storefront category sidebar.
---

The shopper-facing navigation should support nested parent, child, and subchild groups. Keep imported products assigned to their verified source leaf categories; parent navigation pages should include products from descendant categories. Do not repurpose the "Shop By Brand" page as a product category; use the Brands listing.

**Why:** the user explicitly requested nested categories in the shopper sidebar and products under the relevant category paths.

**How to apply:** create clear navigation-only parent groups when source nesting is absent, retain source-category product links at leaf nodes, and aggregate descendants when a parent group is opened.
